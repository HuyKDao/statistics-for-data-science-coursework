# Statistics for Data Science Coursework (Penn ESE 5420)

Write-ups of the homework sets I completed in **ESE 5420: Statistics for Data Science** at the University of Pennsylvania (Spring 2026). The course builds the statistical foundation behind data science: probability, estimation, hypothesis testing, regression and classification, and unsupervised learning. Each set combined written derivations with Python work in Colab.

> **About the code:** the course reuses its homework, so each folder explains the topics, what I did and what I learned instead of posting solutions. I'm happy to walk through my work in an interview.

## Skills and tools
Probability distributions, Central Limit Theorem, confidence intervals, maximum likelihood estimation, method of moments, Fisher information, z-tests and t-tests, p-values, power analysis, likelihood ratio tests, linear regression inference, logistic regression from scratch with gradient descent, LDA, k-fold cross-validation, k-means, PCA, Python, NumPy, pandas, SciPy, scikit-learn, Matplotlib, Seaborn, Google Colab.
